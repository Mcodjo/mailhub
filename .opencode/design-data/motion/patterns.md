# Catalogue de patterns motion

Liste de départ des familles de patterns que `drx-motion` choisit pour une frame. Chaque entrée donne l'intention et les points de vigilance. À enrichir au fil des films.

| Pattern | Intention | Vigilance |
|---|---|---|
| titlecard-reveal | Ouvrir sur un titre fort | Lisibilité dès la première image |
| kinetic-type-beats | Texte en mouvement calé sur les temps | Un mot par battement ; captions synchronisées |
| typewriter-reveal | Texte qui s'écrit | Vitesse de lecture confortable |
| video-text-pivot | Faire basculer le regard d'une image vers un texte clé | Handoff précis |
| dataviz-countup | Chiffre qui monte | Valeur finale lisible et stable |
| comparison-split | Avant / après, A / B | Symétrie et lecture gauche-droite |
| grid-card-assemble | Cartes qui s'assemblent en grille | Ordre d'apparition guidé par le regard |
| cursor-ui-demo | Démonstration d'interface avec curseur | Clics et états visibles |
| prompt-type-submit-generate | Saisie, envoi, résultat généré | Durées réalistes |
| agent-progress-theater | Progression d'un processus automatique | Étapes nommées, pas de jargon |
| transcript-scroll-artifact-reveal | Transcription qui défile puis révèle un résultat | Contraste de texte |
| device-surface-showcase | Mise en scène d'un écran d'appareil | Cadrage et reflets modérés |
| constellation-hub | Éléments reliés à un centre | Lisibilité des liens |
| camera-journey | Parcours de caméra dans un espace | Handoffs de caméra explicites |
| spatial-pan-stations | Panoramique entre stations | Une idée par station |
| overwhelm-surround | Montrer l'excès ou le désordre | Rester lisible, pas d'effet stroboscopique |
| ticker-takeover | Bandeau qui prend le plein écran | Pas de flash |
| fixed-anchor-cycle | Cycle autour d'un élément fixe | Boucle propre |
| cta-morph-press | Appel à l'action qui se transforme puis se presse | Clarté du dernier état |
| logo-assemble-lockup | Logo qui s'assemble en signature | Version statique du logo |
| panel-edit-live-sync | Panneau modifié avec synchronisation en direct | Cause et effet clairement liés |
| zoom-out-workspace-reveal | Dézoom pour révéler l'ensemble | Hiérarchie de lecture |

## Règles d'usage

- Un pattern par frame ; une frame ne mélange pas deux patterns.
- Le pattern décrit l'intention ; la direction artistique reste celle de `drx-design`.
- Tout pattern déclare son repli sans mouvement.
