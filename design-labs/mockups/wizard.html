Connexion Gmail et test final

MailPro Hub envoie via Gmail SMTP relié à votre compte Google.

5a — Autoriser Gmail

Compte Google : maurice@gmail.com

MailPro Hub demandera l'accès en envoi (SMTP) uniquement. Aucune lecture de votre boîte personnelle.

Autorisation refusée — MailPro Hub ne peut pas envoyer de mails sans l'accès SMTP. Relancez la connexion puis acceptez la demande d'autorisation Google.

5b — Alias « Envoyer en tant que »

Dans Gmail, ajoutez l'adresse professionnelle comme alias. Google vous enverra un code de vérification qui arrive dans votre boîte MailPro Hub, sur l'adresse pro.

Alias vérifié : Gmail accepte l'envoi au nom de contact@client-lumen.com.

5c — Test d'envoi et de réception

Envoi : message de test livré à prenom@exemple.com depuis contact@client-lumen.com (délivarabilité 9,4/10 — mail-tester).
Réception : message accusé de réception arrivé dans contact@client-lumen.com via Cloudflare Worker (temps d'acheminement 2,1 s).

Domaine et préfixe

Le domaine doit être hébergé sur Cloudflare. Le préfixe définit votre première boîte (ex. contact@mon-domaine.fr).

Connexion à l'API Cloudflare

Créez un token avec les permissions Zone / DNS / Edit et Email Routing / Edit. Vos identifiants sont chiffrés et ne sont jamais affichés après validation.
