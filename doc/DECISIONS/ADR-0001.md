# ADR-0001 — Stack backend Laravel + MySQL

## Statut : Accepte (validation L8 le 2026-11-04)

## Contexte
CDC v2.0 recommande Laravel. Alternatives evaluees : Node.js (NestJS/Express), Python (Django).
Besoin : API REST, auth, chiffrement de champ natif (tokens OAuth), queues async pour les mails
entrants, WebSocket temps reel, delivery rapide.

## Decision
Laravel (PHP 8.4) + MySQL (MariaDB 11.8 local), avec :
- encrypted casts natifs pour les tokens OAuth et le token API Cloudflare ;
- Laravel Queues pour le traitement async du webhook inbound ;
- Laravel Reverb pour le temps reel (fallback polling 30s).

## Consequences
Positives : batteries incluses couvrant 100% des exigences du CDC, ecosystem mature,
hosting Railway/Render simple, certifs email/API documentees pour les snippets F10.
Negatives : deux runtimes (PHP + Node pour le frontend), rendu Blade inutilise (API only),
Reverb a heberger soit-meme.

## Alternatives rejetees
- Node.js : duplication de logique d'auth/chiffrement a reimplementer, ORM moins direct pour le CDC.
- Django : rapide aussi, mais ecosystem WebSocket/SSE moins ready-made que Reverb pour ce cas.
